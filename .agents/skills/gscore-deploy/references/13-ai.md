# 十三、AI 核心部署要点

> **返回主入口**：[`../SKILL.md`](../SKILL.md) · **上一章**：[十二、Docker 部署](./12-docker.md) · **下一章**：[十四、升级与热更新](./14-upgrade.md)

GsCore 内置 **AI Core** 子系统，提供 AI 工具调用、RAG 检索、多 Agent、人格、
记忆、MCP 等能力。本章讲**部署者角度**怎么开关、配 Key、避免常见坑。

源码目录：[`gsuid_core/ai_core/`](../../../gsuid_core/ai_core/)（30+ 模块）。
**用户文档**：https://docs.sayu-bot.com/AIFeatures/（配置文档在 `Advance/AIConfig.md`）。

## 13.1 启用 AI

**默认关闭**。`data/ai_core/ai_config.json`：

```json
{
  "enable": false,
  ...
}
```

启用：

1. WebConsole → **AI 配置** → 「基础配置」 → 打开「启用AI服务」
2. 配 OpenAI 兼容模型 profile（见 §13.3）
3. 配外部服务 Key（见 §13.4）
4. `core重启`

启动日志应能看到：

```
🧠 AI工具: 12 | 🔗 Trigger工具: 5 | 🎭 人格: 3 | 📋 配置文件: 2
```

> 没看到这一行 → AI 没启用。

## 13.2 ai_config.json 字段速查

源码：[`gsuid_core/ai_core/configs/ai_config.py`](../../../gsuid_core/ai_core/configs/ai_config.py)

| 字段 | 默认 | 说明 |
|------|------|------|
| `enable` | `false` | 总开关 |
| `ai_mode` | `["提及应答"]` | AI 行动入口：`提及应答` / `定时巡检` / `趣向捕捉` / `困境救场` |
| `enable_rerank` | `false` | 启用 Rerank（提升 RAG 质量，模型约 1GB） |
| `enable_memory` | `true` | 启用记忆子系统 |
| `high_level_provider_config_name` | `""` | 高级任务（工具调用）模型 profile，格式 `provider++name`（如 `openai++MiniMAX`） |
| `low_level_provider_config_name` | `""` | 低级任务（简单问答）模型 profile |
| `embedding_provider` | `local` | 嵌入提供方（`local` / `openai`） |
| `rerank_provider` | `local` | Rerank 提供方（`local` / `openai`） |
| `qdrant_provider` | `local` | Qdrant 向量库部署（`local` 嵌入式 / `remote` 远程） |
| `websearch_provider` | **`AnySearch`** | 网络搜索主用（`AnySearch` / `Firecrawl` / `Tavily` / `Jina` / `Exa` / `MCP`）。未填或主用无 Key 时走 AnySearch 匿名额度 |
| `websearch_lb_strategy` | **`error_switch`** | 多源策略：`none` / `error_switch` / `auto_balance`（异常**或空结果**换源） |
| `websearch_fallback_order` | `[]` | 备用源顺序；空=自动收集已配置源（AnySearch→Firecrawl→Tavily→Exa→Jina→MCP） |
| `webfetch_provider` | **`Jina`** | 网页抓取主用（`Jina` / `local`；Jina Key 可选） |
| `webfetch_lb_strategy` | **`error_switch`** | 抓取多源策略（同搜索） |
| `webfetch_fallback_order` | **`["local"]`** | 抓取备用；默认本机直连 |
| `image_understand_provider` | `MCP` | 图片理解（MCP） |
| `asr_provider` | `MCP` | 语音识别（MCP） |
| `video_understand_provider` | `MCP` | 视频理解（MCP） |
| `document_extract_provider` | `MCP` | 文档提取（MCP） |
| `multi_agent_lenth` | `20` | AI 最大思考轮数（防死循环烧 token） |
| `white_list` | `[]` | AI 白名单用户 |
| `black_list` | `[]` | AI 黑名单用户 |
| `hf_endpoint` | `https://hf-mirror.com` | HuggingFace 镜像（local 嵌入下载用） |
| `output_firewall_enable` | `true` | 出戏防火墙：回复下发前检测模型名/AI自指/系统术语，命中让 Agent 重说一次后放行 |
| `output_firewall_extra_terms` | `[]` | 部署者补充禁词（**把自家所用模型名加进来**，内置词库不可能预知你的供应商） |
| `content_guard_enable` | `true` | 内容守卫：疑似"伪造工具返回"的用户消息降权标注（低俗/钓鱼防线在 system prompt 层，无词库） |
| `favor_floor` / `favor_ceil` | `-100` / `100` | 好感度钳制上下限 |
| `favor_daily_decay` | `1` | 好感度每日向 0 回归步长（0=关）；防"刷分锁高档" |
| `agent_max_history` | **30** | 单会话注入模型的最大历史消息条数。工具型 run 单轮消息多，过小会频繁 compact、前缀缓存失效；options 含 10~80 |
| `tool_recall_threshold` | `0.38` | 工具向量召回相关度下限；调高更严、调低更宽 |
| `knowledge_recall_threshold` | **0.35** | 知识库 dense 分支余弦下限（挡跨域低相关条目）；BM25 词命中不受影响 |

> **前缀缓存**：会话内 system 默认不改串；history 超水位时**保头裁中段**。详见
> [gscore-development §6.7.1](../../gscore-development/references/06-ai-session-and-persona.md)。

> **安全防线观察**：`[OutputFirewall]` 的 warning 日志区分"要求重写"与"重写后仍命中放行"
> 两类，上线初期建议拉取统计误杀率/重写服从率，据此增删词库（详见
> [`docs/SESSION_LOG_SECURITY_FINDINGS_20260707.md`](../../../../docs/SESSION_LOG_SECURITY_FINDINGS_20260707.md)）。

> **`hf_endpoint` 在 Core 启动早期就被读入**（见 [`core.py:74-77`](../../../gsuid_core/core.py)），
> 改完要 `core重启`。

## 13.3 模型 Profile（OpenAI 兼容）

每个 LLM 模型是一个 **profile**，文件位置：

```
data/ai_core/
├── provider_configs/
│   ├── openai/
│   │   ├── MiniMAX.json
│   │   ├── DeepSeek.json
│   │   └── ...
│   ├── anthropic/
│   └── gemini/
├── openai_config.json       # 索引文件，列出所有 profile
├── anthropic_config.json
└── gemini_config.json
```

**profile 示例**（`MiniMAX.json`）：

```json
{
  "base_url": "https://api.MiniMAX.com/v1",
  "model_name": "MiniMax-Text-01",
  "api_key": "sk-xxx",
  "model_support": ["text"]
}
```

| 字段 | 说明 |
|------|------|
| `base_url` | API 基础 URL（OpenAI 兼容） |
| `model_name` | 模型名 |
| `api_key` | API 密钥 |
| `model_support` | `["text"]` / `["text", "image"]` / `["text", "image", "audio"]` / `["text", "image", "audio", "video"]` |
| `forward_end_user_id` | 仅 OpenAI 兼容 profile：`off`（默认）/ `hashed` / `raw`，控制是否向请求体携带 `user` 字段 |
| `end_user_id_salt` | `hashed` 模式的盐值（secret）；留空为无密钥摘要 |

> **建议**：WebConsole → AI 配置 → 「模型配置」 直接加 / 改 profile（自动
> 校验 URL / 测连通性）。

### 13.3.1 自建网关：按人鉴权与归属

对接**自建 OpenAI 兼容网关**（按登录用户验签、限额）时，常见组合：

1. profile `base_url` 指向网关；`api_key` 填**服务凭据**（供后台 run 等无登录态场景兜底）。
2. 对该 profile 设 `forward_end_user_id=raw`（或 `hashed` + 盐值），把框架归属里的 `user_id`
   带给网关日志。
3. 若网关要求用户 JWT 鉴权，由宿主注册 `register_attribution_resolver`，在交互 run 的
   `extra_headers` 里附带 `Authorization`；解析器拿不到凭据时自动落回服务凭据。

鉴权身份（`Authorization` / `api_key`）与归属标识（请求体 `user`）是两层信息：网关日志应能
分别观测。详见 WebConsole 文档 `24-provider-config.md`「终端用户标识透传」。

## 13.4 外部服务 Key

### 13.4.0 Tavily（备选网络搜索）

- 注册：https://tavily.com
- 免费额度：约 1000 次 / 月
- 配置：`data/ai_core/tavily_config.json`

```json
{
  "api_key": ["tvly-xxx"],
  "max_results": 10,
  "search_depth": "advanced"
}
```

`search_depth`：`basic`（快）/ `advanced`（更详细但慢）。
额度用尽 / Key 失败会**抛错**；空结果也会触发换源。配合 `websearch_lb_strategy=error_switch` 可切到 Jina/Exa 等。

### 13.4.1 Jina（搜索备选 + 默认网页抓取）

- 控制台：https://jina.ai / Reader 文档
- 配置：`data/ai_core/jina_config.json`（搜索与抓取共用）

```json
{
  "api_key": ["jina_xxx"],
  "max_results": 10,
  "timeout": 30,
  "search_base_url": "https://s.jina.ai",
  "reader_base_url": "https://r.jina.ai"
}
```

| 能力 | 端点 | Key |
|------|------|-----|
| 搜索（`websearch_provider=Jina`） | `s.jina.ai` | **必填**（无 Key 401） |
| 抓取（默认 `webfetch_provider=Jina`） | `r.jina.ai/{url}` | **可选**（匿名有额度；填 Key 更高） |

WebConsole → **AI 配置** → 「网络搜索服务」/「网页抓取服务」可改主用、多源策略与备用顺序；**热生效，无需重启**。

### 13.4.2 Exa（备选网络搜索）

`data/ai_core/exa_config.json`：

```json
{ "api_key": ["exa-xxx"], "max_results": 10 }
```

### 13.4.2a AnySearch（默认网络搜索主用，Key 可选）

- 文档：https://www.anysearch.com/docs#quick-start
- 控制台：https://anysearch.com/console/api-keys
- 端点：`POST https://api.anysearch.com/v1/search`
- 配置：`data/ai_core/anysearch_config.json`

```json
{
  "api_key": [],
  "max_results": 10,
  "timeout": 30,
  "zone": "",
  "language": ""
}
```

| 项 | 说明 |
|----|------|
| `api_key` | **可选**。空则匿名（按 IP 限流 + 每日免费额度）。填 Key 走更高额度。无效 Key **不会**回落匿名 |
| `max_results` | 1–100，默认 10 |
| `zone` | `cn` / `intl`；留空不传 |
| `language` | `zh-CN` / `en`；留空不传 |

未配置主用、主用无 Key、或备用链留空时，都会走 AnySearch 匿名额度。填写 API Key 可提高限流。

### 13.4.2b Firecrawl（备选网络搜索，Key 可选）

- 文档：https://docs.firecrawl.dev/sdks/python
- 控制台：https://www.firecrawl.dev
- SDK：`firecrawl-py` → `AsyncFirecrawl.search`（`POST /v2/search`）
- 配置：`data/ai_core/firecrawl_config.json`

```json
{
  "api_key": [],
  "max_results": 10,
  "timeout": 30
}
```

| 项 | 说明 |
|----|------|
| `api_key` | **可选**。空则走 keyless 免费档（按 IP 限流）。填 Key 提高额度。无效 Key **不会**回落匿名 |
| `max_results` | 1–100，默认 10 |
| `timeout` | 秒；SDK 以毫秒下发 |

`scrape` / `search` / `interact` 可无密钥；其它 Firecrawl 方法（crawl 等）本框架搜索源不会调用。

### 13.4.2c 本机网页抓取（local）

`webfetch_provider=local` 或作为 Jina 备用时：`data/ai_core/web_fetch_config.json`
（proxy / trust_env / timeout / User-Agent / max_download_mb / max_content_length）。无需第三方 Key。

### 13.4.3 Qdrant（远程向量库）

`qdrant_provider=remote` 时配 `data/ai_core/qdrant_config.json`：

```json
{
  "url": "https://qdrant.example.com:6333",
  "api_key": "xxx"
}
```

> `local` 模式无需配置，使用嵌入式 Qdrant + LMDB 存储。

### 13.4.4 MCP Server

MCP（Model Context Protocol）提供图片理解 / 语音识别 / 视频理解 / 文档提取等
能力。`data/ai_core/mcp_config/` 下放每个 server 的配置。

详见：[`docs/MCP_SERVER.md`](../../../../docs/MCP_SERVER.md)。

## 13.5 资源消耗

| 组件 | 磁盘 | 内存 | 备注 |
|------|------|------|------|
| 嵌入模型（local） | ~300 MB | ~300 MB | 首次启动从 HF 下载 |
| Rerank 模型（local，可选） | ~1 GB | ~1 GB | 启用后吃内存 |
| Qdrant local | 数据量相关 | 与数据量相关 | 嵌入式 |
| OpenAI 兼容 LLM API | - | - | 按 token 计费 |

> **建议**：启用 `enable_rerank=true` 前确认机器 ≥ 2GB 内存。

## 13.6 部署建议

### 13.6.1 小规模（个人 / 小群）

- `embedding_provider=local` + 默认 `websearch_provider=AnySearch`（无需 Key；可选再配 Firecrawl/Tavily/Jina/Exa 作备用）
- 抓取默认 Jina（Key 可选），备用 local（`webfetch_*` 默认即可）
- 一个 OpenAI 兼容 profile（如 DeepSeek / 智谱 GLM）
- `multi_agent_lenth=12` 省 token

### 13.6.2 中规模（生产）

- 启用 `enable_rerank=true`
- `qdrant_provider=remote`（独立 Qdrant 容器 / 服务）
- 高级任务用贵的模型（如 GPT-4 / Claude Sonnet）
- 低级任务用便宜模型（如 GPT-4o-mini / DeepSeek）

### 13.6.3 安全

- `white_list` / `black_list` 严格控制谁能用 AI（避免 token 被刷）
- `multi_agent_lenth` 不超过 30（防递归死循环）
- WebConsole 改 model profile 后**立即生效**（多数可热更）

## 13.7 故障排查

| 现象 | 原因 / 解决 |
|------|--------------|
| 启动没 AI 日志 | `enable=false` / 配置文件没读到 |
| 嵌入模型下载失败 | `hf_endpoint` 设错 / 网络限；切 `https://hf-mirror.com` |
| LLM API 调不通 | `base_url` / `api_key` 错；先 curl 测连通 |
| Rerank 启用后内存爆 | 机器太小；用 `openai` 远程 rerank |
| Web search 报 401 / 空结果一直换源 | Tavily/Jina/Exa Key 错或过期；Jina **搜索**无 Key 必 401；AnySearch / Firecrawl 无 Key 走匿名/keyless，无效 Key 不会回落匿名；空结果会按策略切下一源 |
| 抓取慢/限流 | Jina 匿名额度；填 `jina_config.api_key` 或策略切到 local |
| 日志看不出抓取源 | 应见 `[WebFetch] 开始抓取 provider=Jina|local`；升级 core |
| 工具「超过 100 秒」超时 | `web_search_tool` / `web_fetch_tool` 外层 100s；缩短单源 timeout 或减备用源 |
| Qdrant remote 连不上 | URL / 端口 / api_key 错；先 `curl <url>/healthz` |
| 切换 qdrant_provider 不生效 | 启动时会自动迁移历史数据，等迁移完再测 |
| `multi_agent_lenth` 太大 token 烧光 | 调到 12 或 9 |

## 13.8 不启用 AI

AI 完全可以不开：

- `enable=false`
- 所有 `*_provider` 字段即使配了也不会被调用
- 不会下载嵌入模型（首次启动会跳过）
- Core 启动不会拉 AI 核心后台初始化

> Bot 业务功能（命令、数据库、插件）**不依赖 AI**。
> HTTP Agent 面也不会挂上（`/api/v1/agent/*` 404）。Admin 建钥仍可用。

## 13.8b HTTP 流式 Agent API

还须 AI 总开关 `enable=true`。AI 关着时启动**不挂** `/api/v1/agent/*`；中途关掉 AI 也会 404。
打开 AI 后需重启才会挂 Agent 面。

默认关：`data/ai_core/http_agent_api.json` 的 `enable_http_agent_api=false` →
`/api/v1/agent/*` **404**（路由仍在，可热开）。Admin 建钥
`POST /api/http-agent/admin/keys`（WebConsole 管理员 Bearer）在两开关都关时仍可用。
打开后客户端用 `Authorization: Bearer gsk_...` 调
`POST /api/v1/agent/chat/stream`（SSE）。

- 不要用 `WS_TOKEN` / 控制台会话当 Agent 鉴权。
- 单 worker；nginx 须 `proxy_buffering off`，`proxy_read_timeout` ≥ 墙钟，并设
  `X-Real-IP` / `X-Forwarded-For`（`TRUSTED_IPS` 含反代地址才认）。
- v1 无 tool/thinking SSE；同 session 后到抢答先到。上行图片只收内联 base64。
  `group_id` 可选：省略/`null` 私聊；有值则同 `bot_id` 的钥共享该群。
- 实机脚本：`eval/manual/http_agent_stream.py`。
- 前端 / 客户端对接：[`docs/HTTP_AGENT_API.md`](../../../../docs/HTTP_AGENT_API.md)。
