# 0.12.3 — 表情包语义协议、混合检索与控制台批量管理升级

发布于 2026-11-27 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

表情包启用短语标签协议、向量与词面混合检索及双轨缩放，采集改入独立隔离包，控制台新增批量启停与强制补全识别。

- **✨ 新增** 表情包改用短语标签与纯表情回复，合并向量和词面检索，入库 400 px、发图 128 px，默认冷却降至 15 秒。 [`1b9bde35`](https://github.com/Genshin-bots/gsuid_core/commit/1b9bde35)
- **✨ 新增** 表情包市场上线：浏览 CNB 官方目录并免克隆预览，单分支安装、增量更新与卸载，可挂载多个人格，支持自定义 Git 仓库导入。
- **🎨 调整** 自动采集改入独立「群聊采集」包待人工调包后再发，上限调至 2048 KB / 1280 px；控制台新增标题配字编辑、批量启停与强制补全。 [`1b9bde35`](https://github.com/Genshin-bots/gsuid_core/commit/1b9bde35)
- **✨ 新增** 控制台记忆范围卡显示名称与头像，点击卡片或统计项可进入对应范围详情。 [`88bbde01`](https://github.com/Genshin-bots/gsuid_core/commit/88bbde01)
