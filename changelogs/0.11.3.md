# 0.11.3 — 依赖刷新到最新兼容版

发布于 2026-11-07 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

全部 Python 依赖刷新到当前兼容最新版，`uv.lock` / `poetry.lock` / `pdm.lock` / `requirements.txt` 同步重生成。

- **⬆️ 依赖** 全部依赖刷新至当前兼容最新版（`fastapi` 0.162、`pydantic-ai-slim` 2.66、`anthropic` 2.6、`pillow` 13 等）。
- **🔖 升版** 升版至 `0.11.3`。
- **🔌 新增** MCP 服务广场：接 ModelScope 目录，可搜索、按传输变体预览后一键安装成 MCP 配置；上游不可达时回落本地预置卡片。服务 logo 由后端代理拉取并缓存在 `data/` 本地目录，拉取失败不影响列表与安装。
- **🔌 新增** 启用的 MCP 服务自动生成「能力代理节点」（source=mcp），不进主人格花名册；节点描述可由 LLM 高档位异步补全并直接生效，面板上的改名/改描述落盘为覆盖层，不污染自动生成基线。
- **🐛 修复** `register_as_ai_tools` 现在真正生效：关闭后 MCP 服务只注册能力节点、不直挂工具；注销 MCP 工具按服务名精确匹配，不再误删其它服务的同名前缀工具。
- **💥 变更** MCP 配置引入 `schema_version`：启动时旧版本配置文件自动迁移（统一打开 `register_as_ai_tools`）并写回磁盘。
- **🎨 调整** `find_tools` 对同一 MCP server 的直调工具最多暴露 2 个，命中时对应能力节点必入专用档，引导走委派而非逐个直调。
