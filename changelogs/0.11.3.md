# 0.11.3 — 依赖刷新到最新兼容版

发布于 2026-11-07 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

全部 Python 依赖刷新到当前兼容最新版，`uv.lock` / `poetry.lock` / `pdm.lock` / `requirements.txt` 同步重生成。

- **⬆️ 依赖** 全部依赖刷新至当前兼容最新版（`fastapi` 0.162、`pydantic-ai-slim` 2.66、`anthropic` 2.6、`pillow` 13 等）。[`5249af26`](https://github.com/Genshin-bots/gsuid_core/commit/5249af26)
- **🔖 升版** 升版至 `0.11.3`。[`5249af26`](https://github.com/Genshin-bots/gsuid_core/commit/5249af26)
- **🔌 新增** MCP 服务广场：接 ModelScope 目录，可搜索、按传输变体预览后一键安装成 MCP 配置；上游不可达时回落本地预置卡片。服务 logo 由后端代理拉取并缓存在 `data/` 本地目录，拉取失败不影响列表与安装。[`5249af26`](https://github.com/Genshin-bots/gsuid_core/commit/5249af26)
- **🔌 新增** 启用的 MCP 服务自动生成「能力代理节点」（source=mcp），不进主人格花名册；节点描述可由 LLM 高档位异步补全并直接生效，面板上的改名/改描述落盘为覆盖层，不污染自动生成基线。[`5249af26`](https://github.com/Genshin-bots/gsuid_core/commit/5249af26)
- **🐛 修复** `register_as_ai_tools` 现在真正生效：关闭后 MCP 服务只注册能力节点、不直挂工具；注销 MCP 工具按服务名精确匹配，不再误删其它服务的同名前缀工具。[`5249af26`](https://github.com/Genshin-bots/gsuid_core/commit/5249af26)
- **💥 变更** MCP 配置引入 `schema_version`：启动时旧版本配置文件自动迁移（统一打开 `register_as_ai_tools`）并写回磁盘。[`5249af26`](https://github.com/Genshin-bots/gsuid_core/commit/5249af26)
- **🎨 调整** `find_tools` 对同一 MCP server 的直调工具最多暴露 2 个，命中时对应能力节点必入专用档，引导走委派而非逐个直调。[`5249af26`](https://github.com/Genshin-bots/gsuid_core/commit/5249af26)
- **🐛 修复** 插件商店列表请求遵循系统 `HTTP_PROXY`/`HTTPS_PROXY` 环境变量，修复代理环境下刷新插件商店与切换 Git 镜像源失败。[`7fffc7ef`](https://github.com/Genshin-bots/gsuid_core/commit/7fffc7ef)
- **🐛 修复** 用 `uv run core` 启动时，`core重启` 拉起新 core 之前，守护父进程先执行 `uv sync --inexact --no-install-project`。`core更新` 拉到的版本新加了依赖时，重启后不再因缺包起不来。[`ee58a96a`](https://github.com/Genshin-bots/gsuid_core/commit/ee58a96a)
- **🐛 修复** Windows 上 `core更新` 的依赖安装改为 `uv sync --inexact --no-install-project`。之前 `pyproject.toml` 一改，uv 重装 core 本身时删不掉正在运行的 `core.exe`，整次安装失败，新依赖也装不上。[`ee58a96a`](https://github.com/Genshin-bots/gsuid_core/commit/ee58a96a)
- **💥 变更** 删除配置项「每日扣分上限」，好感度扣分上限固定为每天 20 分。
- **🎨 调整** 记忆生命周期维护改为每日 04:00 执行，分层衰减群组闲聊（7天/0.8）与用户属性（14天/0.85），孤儿实体回收由 10 天降至 3 天。
- **🔒 安全** 自主行动私聊引入发送门控：仅在目标为主人、存在既有私聊记录或群内显式请求私聊时允许主动发送。
- **🐛 修复** 修复插件别名跨群污染与命令文本误入上下文，增加段子抽取短路过滤与发言提及人消歧。
