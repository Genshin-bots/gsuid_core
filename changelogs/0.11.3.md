# 0.11.3 — 依赖刷新到最新兼容版

发布于 2026-11-07 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

全部 Python 依赖刷新到当前兼容最新版，`uv.lock` / `poetry.lock` / `pdm.lock` / `requirements.txt` 同步重生成。

- **⬆️ 依赖** 全部依赖刷新至当前兼容最新版（`fastapi` 0.162、`pydantic-ai-slim` 2.66、`anthropic` 2.6、`pillow` 13 等）。[`5249af26`](https://github.com/Genshin-bots/gsuid_core/commit/5249af26)
- **🔖 升版** 升版至 `0.11.3`。[`5249af26`](https://github.com/Genshin-bots/gsuid_core/commit/5249af26)
- **🔌 新增** MCP 服务广场接入 ModelScope 目录，支持搜索、按传输变体预览与一键安装；启用的 MCP 服务自动生成能力代理节点，支持异步补全描述与面板覆盖。[`5249af26`](https://github.com/Genshin-bots/gsuid_core/commit/5249af26)
- **💥 变更** MCP 配置引入 `schema_version` 启动自动迁移；`register_as_ai_tools` 生效，关闭后仅注册能力节点，`find_tools` 对同一服务最多暴露 2 个直调工具。[`5249af26`](https://github.com/Genshin-bots/gsuid_core/commit/5249af26)
- **🐛 修复** 插件商店列表请求遵循 `HTTP_PROXY`/`HTTPS_PROXY`；`core重启` 与 Windows `core更新` 改用 `uv sync --inexact --no-install-project` 避免缺包或 `core.exe` 占用。[`7fffc7ef`](https://github.com/Genshin-bots/gsuid_core/commit/7fffc7ef) [`ee58a96a`](https://github.com/Genshin-bots/gsuid_core/commit/ee58a96a)
- **💥 变更** 删除配置项「每日扣分上限」，好感度扣分上限固定为每天 20 分；记忆生命周期改为每日 04:00 分层衰减，孤儿实体回收缩至 3 天。[`5f9694bb`](https://github.com/Genshin-bots/gsuid_core/commit/5f9694bb)
- **🔒 安全** 自主行动私聊仅在目标为主人、有既有私聊记录或显式请求时允许发送；修复插件别名跨群污染与命令文本误入上下文。[`5f9694bb`](https://github.com/Genshin-bots/gsuid_core/commit/5f9694bb)
