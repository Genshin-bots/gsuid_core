# 0.11.1 — token 用量恢复记账，`pydantic-ai-slim` 升到 2.54

发布于 2026-10-08 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

`genai-prices` 0.1.x 会让每次模型调用的用量记成 0。这一版升到 `pydantic-ai-slim` 2.54.0 与 `genai-prices` 0.1.9。

- **🐛 修复** `genai-prices` 0.1.x 多带的用量键让提取失败，日历、预算账本和 TPS 都记成 0。`pydantic-ai-slim` 提到 `>=2.54.0`，`genai-prices` 改为 `>=0.1.9`。`openai` 与 `anthropic` 改走 `httpx2` 池，`gemini` 仍走 `httpx` 池。[`a0672904`](https://github.com/Genshin-bots/gsuid_core/commit/a0672904)
- **⬆️ 依赖** `pydantic-ai-skills` 约束到 `<1`，避免 Windows 上构造技能能力抛 `NotImplementedError`。`pytakumi` 最低版本提到 `0.1.5`。`gsuid_core/version.py` 从 `0.10.7` 对齐到 `0.11.1`。[`a0672904`](https://github.com/Genshin-bots/gsuid_core/commit/a0672904)
- **⬆️ 依赖** `starlette`、`fastapi`、`fastmcp`、`sqlmodel`、`pillow` 补上能装上的下限。三份锁文件按同一套约束重解：113 个包升到约束内的最新版，其中 20 个是主版本跳。发送日志时的断连判定改为「连接已掉出 `CONNECTED`」，不再依赖只有 starlette 1.7.0 才有的类名。[`9880335f`](https://github.com/Genshin-bots/gsuid_core/commit/9880335f)
- **🎨 调整** Core 给插件补依赖时只读 `UV_DEFAULT_INDEX`。未设置或为空白时使用 `https://pypi.org/simple`。安装失败即停止，不再依次尝试镜像源。[`295ce074`](https://github.com/Genshin-bots/gsuid_core/commit/295ce074)
- **✨ 新增** 网页控制台数据库页可导入 CSV。增量（默认）按主键更新并插入，其余行保留；覆盖先清空该表再写入。确认后还要再确认三次，第三次输入表名。[`fb80b874`](https://github.com/Genshin-bots/gsuid_core/commit/fb80b874)
- **🎨 调整** 群聊只有在问过往记录或私聊问答时才注入「这是在问已有记忆」。闲聊长度跟人格 `chat_style`。口吻锚只留说话节奏。宪法不再按次数拒绝重复发言，关系口气只写冷热。[`a0388071`](https://github.com/Genshin-bots/gsuid_core/commit/a0388071)
- **🐛 修复** 群里只发图也会写入历史。「看看这是谁」在前 1～2 条有图、且任务是看图时不再打回。带括号的 `<沉默>` / `[沉默]` 认成协议沉默，裸「沉默」仍当台词。表情包和主人格出图记进当前说话人线程。[`a0388071`](https://github.com/Genshin-bots/gsuid_core/commit/a0388071)
- **✨ 新增** 模型可以调用 `run_code` 写一段 Python，只允许 `await` 本轮已暴露且 `code_callable=True` 的工具。发消息、写入、委派标成 False。整段脚本墙钟 230 秒，到点会取消还在跑的搜索或抓页。模型只拿回最后一行表达式。[`b71ebe64`](https://github.com/Genshin-bots/gsuid_core/commit/b71ebe64)
- **🐛 修复** 评测清场按字面量匹配 `eval_`。`evaluation`、`eval-` 开头的待办和好感不再被清掉。[`b71ebe64`](https://github.com/Genshin-bots/gsuid_core/commit/b71ebe64)
- **🎨 调整** 宪法区分闲聊和办事：闲聊不当工单，记忆片段不当清单汇报，禁止客服式留退路。心跳在话题发出 3～20 分钟、且判定可搭话时，注入「几分钟前发出」。[`5968b8a4`](https://github.com/Genshin-bots/gsuid_core/commit/5968b8a4)
- **⚡ 性能** 能力代理花名册单行上限改为配置项 `capability_roster_line_max`，默认 45 字。本机一次闲聊的 input token 从约 20000 降到约 7400。没有系统校验指令时不向模型暴露 `dispute_directive`。[`5968b8a4`](https://github.com/Genshin-bots/gsuid_core/commit/5968b8a4)
- **🎨 调整** `render_agent` 去掉单侧粗线。时序图要有水平网格和真实 Y 轴刻度。写了 `background` 就必须同级写 `color`。[`5968b8a4`](https://github.com/Genshin-bots/gsuid_core/commit/5968b8a4)
- **🐛 修复** `core重启` 在多连接或重连时不再偶发发两次回执。目标 Bot 还没连入时保留重启订阅。[`9a6a2641`](https://github.com/Genshin-bots/gsuid_core/commit/9a6a2641)
- **⚡ 性能** 意图分类不再加载 scikit-learn 和 jieba。最初 65 句上，句式归类平均 0.007 毫秒，导入后工作集多 21MB；旧模型平均 2.44 毫秒，工作集多 244MB。[`70eeeacb`](https://github.com/Genshin-bots/gsuid_core/commit/70eeeacb)
- **🐛 修复** 句式分类按 2026-10-03 至 2026-10-11 的原文校正。九个按日日志里 39993 条有正文的入站，校正后的误判清单还命中 13 条。分享卡里的「打开 / 画图」和陈述里的「没多少」「我哪里」不再标成工具或问答。[`70eeeacb`](https://github.com/Genshin-bots/gsuid_core/commit/70eeeacb)
- **⚡ 性能** AI 总开关关闭时，启动不加载 onnxruntime 和 fastembed，知识库导入为空壳。playwright 仍加载，命令出图不受总开关影响。远程 Qdrant 改走 HTTP；同一套导入下，加载 `qdrant-client` 的进程工作集为 256MB，不加载时为 226MB。[`94d0d21a`](https://github.com/Genshin-bots/gsuid_core/commit/94d0d21a) [`e85a8a06`](https://github.com/Genshin-bots/gsuid_core/commit/e85a8a06) [`70eeeacb`](https://github.com/Genshin-bots/gsuid_core/commit/70eeeacb)
- **💥 破坏性** 移除「HuggingFace 服务器地址」配置。启动不再写入 `HF_ENDPOINT`。已保存的 `hf_endpoint` 不再读取；下载模型时沿用进程环境里的 `HF_ENDPOINT`，没有该变量就访问 huggingface.co。[`94d0d21a`](https://github.com/Genshin-bots/gsuid_core/commit/94d0d21a)
- **⚡ 性能** 网页控制台任务看板改为两次只读查询。根任务约 2000 条时，旧实现打开这一页要几十秒。AI 历史在日志目录和活跃会话都没变时，复用上次的链列表。摘要缓存最多 60 秒写一次。[`630ecd44`](https://github.com/Genshin-bots/gsuid_core/commit/630ecd44)
- **✨ 新增** 插件可在 `pyproject.toml` 的 `[project]` 里声明 `gscore_auto_upgrade_dep`。Core 每次启动把表里的依赖升到约束内的最新版。`gscore_auto_update_dep` 仍只在已装版本不满足约束时更新。两者都只在自动安装或自动更新依赖开启时生效。[`f71c271e`](https://github.com/Genshin-bots/gsuid_core/commit/f71c271e)
- **⚡ 性能** 十分钟一次的命令统计只写入这 10 分钟里变过的格子。没有新命令、收发和人数也没变时不写库。看板 30 天 DISTINCT、每日命令明细和 bot 列表改走只读槽。[`b49b118c`](https://github.com/Genshin-bots/gsuid_core/commit/b49b118c) [`98d15d07`](https://github.com/Genshin-bots/gsuid_core/commit/98d15d07)
- **🎨 调整** 只发了 `send_meme` 时，本轮可以再补一句，也可以 `<SILENCE>`。已经用 `send_message_by_ai` 把台词发出去时，仍只许 `<SILENCE>`。接任务应放行「一行括号动作 + 一行台词」。插画、立绘和生图不交给 `render_agent`。[`82abf420`](https://github.com/Genshin-bots/gsuid_core/commit/82abf420)
- **🐛 修复** 主人自述里的一次性相对日程写入事件记忆，不写入长期偏好。超过 24 小时标成 `（已过期日程）`。没有事实包的数字句照常发出。只有上一轮点了已装配的工具却没调用，下一轮才提醒去调用。会话日志在输出为 `<SILENCE>` 或空文本时写入 `silence_reason`。[`82abf420`](https://github.com/Genshin-bots/gsuid_core/commit/82abf420)
- **🐛 修复** 同一次回复里还有工具调用时，旁边的字先不发出去。委派成功、后台开工之后才发开场句；校验被拒的派发不发。叫人格名不再被写成某个插件的同名实体。没有子步骤在跑的周期托管任务，不再把闲聊算成在途。[`d978c721`](https://github.com/Genshin-bots/gsuid_core/commit/d978c721)
- **💥 破坏性** 移除人格设定「接任务应」（`task_ack`），已保存的值不再读取。框架不再替人格发固定开场句。[`d978c721`](https://github.com/Genshin-bots/gsuid_core/commit/d978c721)
- **⚡ 性能** 记忆检索按时间均匀抽取孤儿候选，注入时按账本时间升序。[`624a3e62`](https://github.com/Genshin-bots/gsuid_core/commit/624a3e62)
- **💥 破坏性** 移除「群聊旁观轮最大思考轮数」（`group_idle_max_iterations`），已保存的值不再读取。主会话每一轮都用「最多允许AI思考轮数」（`multi_agent_lenth`）。[`0a6b97e6`](https://github.com/Genshin-bots/gsuid_core/commit/0a6b97e6)
- **🎨 调整** `create_subagent` 不再核对任务正文是否含有本轮原话的连续片段。模型把专名写错一个字，或把图里的内容写进任务时，委派照常发出。[`0a6b97e6`](https://github.com/Genshin-bots/gsuid_core/commit/0a6b97e6)
- **🐛 修复** Anthropic 返回 400 时，Core 按错误正文改一次再发。思考类型不被接受时改成 adaptive，并记下该模型之后都走 adaptive。思考块绑错前缀时，从回放里拿掉这些签名。`temperature`、`top_p` 或 `top_k` 已废弃时丢掉这三个参数。记下的结论只在本次进程有效。
- **✨ 新增** OpenAI、Anthropic、Gemini 的思考档位增加 `adaptive`。选它时请求不带 `thinking`。`claude-haiku-5-5` 在这种请求上使用 adaptive，默认 effort 为 `medium`。
- **🎨 调整** 默认人格「早柚」的正文由程序种子提供。启动时若 `persona.md` 与种子不同，用种子覆盖。`voice_anchor.txt` 不删除。语气词为「唔、呼、哼、欸」。除非群友先聊睡觉或午休，卡上禁止拿睡觉收尾。
- **✨ 新增** 人格最近 8 条发言里至少有 4 条、且同一个片段在至少 3 条里出现时，本轮在口吻锚前加一行复读提示，最多 3 个片段。这一行写入历史前剥掉。当前问题和这段时间的用户发言里已有的片段不算。
- **🎨 调整** 别名表只在查角色或实体数据时认定插件。关系档「陌生」的口气改为「还不算太熟，语气自然简短」。宪法在没人找你时优先 `<SILENCE>`，要拒绝或纠正时照常回话。用户要求发出 `traceback` 时，人格不能把这个词原样念出来。
- **🐛 修复** 非空 history 缺少系统提示时，补上当前会话的 system prompt。匹配「把他/她/你/我/它的…改成」且句中没有提醒或任务这类词时，不走省略式任务跟进。
- **⚡ 性能** 工具召回、知识库、图片、产物和能力节点的查询向量改走单条嵌入线程池，不再和后台切块索引共用批量池。修改前，本机后台正在索引 2.5 万～3.8 万字的网页时，一次工具召回要排队 6～10 分钟。
- **🐛 修复** 评测重置时，本次用例里出现的说话人在 HTTP bot 下的好感一并清掉，待执行的提醒一并取消。此前这些群友 ID 的好感和提醒会跨轮累积。
