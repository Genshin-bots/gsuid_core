# 0.7.2 — 插件热重载上线，数据库可用 MySQL

发布于 2025-05-18 · 本版 51 个提交 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

插件更新后的重载做成了流程内的一步: 装完或更新完插件，core 自己重载注册，不必再重启。`core信息` 卡片换了数据口径与外观，`MySQL` 数据库经实测也能跑。
