# 0.12.1 — 网页抓取接入 AnySearch Extract

发布于 2026-11-16 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

网页抓取（`webfetch_provider`）新增 AnySearch 源，与搜索共用 Key 池，无 Key 走匿名额度。

- **✨ 新增** 网页抓取提供方新增 AnySearch：经 `/v1/extract` 读取正文，无 Key 时走匿名每日额度。[`06c9b636`](https://github.com/Genshin-bots/gsuid_core/commit/06c9b636)
- **✨ 新增** 备份建议路径：插件登记用户数据/配置/可重下目录，备份页按建议排序、默认勾选用户数据，支持增量保存与目录搬迁。
- **✨ 新增** 备份还原：/backup 页可预检冲突并还原 zip（含分块上传），覆盖前自动备份原文件，主库还原重启生效。
- **🔖 升版** 升版至 `0.12.1`，`gsuid_core/version.py` 从 `0.11.3` 一并对齐：它漏跟 `0.12.0` 升版，状态图与 `core更新记录` 此前把「当前版本」认在 `0.11.3`。[`06c9b636`](https://github.com/Genshin-bots/gsuid_core/commit/06c9b636)
