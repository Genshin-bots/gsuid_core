# 0.11.0（未发布） — 知识嵌入按模型窗口切分，委派内联等待，群聊排队跳过 TTL

发布于 2026-10-07（未发布） · 本版 7 个提交 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

版本号已是 `0.11.0`，但仍有提交落在其后。

- **🐛 修复** 旧连接的收尾只关闭自己的套接字。`close()` 期间同一 `bot_id` 登记了新连接时，收尾不删除该登记，也不把新 `_Bot` 标成已断开。套接字关闭后，`GsLogger` 推日志不再抛出 `WebSocketDisconnected`。
- **🎨 调整** 知识嵌入按当前嵌入模型声明的最大输入 token 折算切分预算，未知模型按 512 token 留 32 个特殊 token；切法编号连同 token 上限一起进内容哈希，换模型会自动重切。[`ef79e92d`](https://github.com/Genshin-bots/gsuid_core/commit/ef79e92d)
- **🎨 调整** `core更新记录` 不带参数时改为同时给未发布段与上一已发布版；索引触发词补上 `目录`、`idx`、`menu`。[`d3d4e48c`](https://github.com/Genshin-bots/gsuid_core/commit/d3d4e48c)
- **🐛 修复** 群聊排队不再等 TTL 到期，委派派完即走，并把消息按发起人传给被委派的 subagent。[`926d3e50`](https://github.com/Genshin-bots/gsuid_core/commit/926d3e50)
- **📝 文档** 补充更新日志的写法约定，并把此前各版本的历史记录补齐。[`ed19361f`](https://github.com/Genshin-bots/gsuid_core/commit/ed19361f)
- **✨ 新增** 撤掉选择器，新增认知检索分页，委派改为内联等待。[`65c3f8c4`](https://github.com/Genshin-bots/gsuid_core/commit/65c3f8c4)
- **🐛 修复** `on_prefix` 触发器的空格匹配问题。[`87c06f11`](https://github.com/Genshin-bots/gsuid_core/commit/87c06f11)
- **🐛 修复** 软触发轮群转录缺失、兜底出戏修复与过程叙述闸。[`5fde13e0`](https://github.com/Genshin-bots/gsuid_core/commit/5fde13e0)
