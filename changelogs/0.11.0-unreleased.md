# 0.11.0（未发布） — 知识嵌入按模型窗口切分，委派内联等待，群聊排队跳过 TTL

发布于 2026-10-07（未发布） · 本版 12 个提交 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

版本号已是 `0.11.0`，但仍有提交落在其后。

- **🐛 修复** 适配器上报的一帧无法解码为 `MessageReceive` 时，Core 写一行警告并跳过该帧。这条 WebSocket 保持连接，不再打出 ASGI 堆栈。[`9e4ad01b`](https://github.com/Genshin-bots/gsuid_core/commit/9e4ad01b)
- **🐛 修复** `core信息` 不再让取数跑在另一个事件循环上。`_draw_status_uncached` 曾被 `pool.to_thread` 装饰，而该装饰器对协程函数会新建事件循环，渲染里的 DB 访问因此跑在一个临时循环上——读信号量会在首次竞争时把 `_loop` 绑到那个随后被 `close()` 的循环，主循环之后的每一次竞争读都会抛 `bound to a different event loop` 且不会自愈。现在取数留在主循环，纯 PIL 装配交 `asyncio.to_thread`。
- **🐛 修复** `core信息` 不再抢占写闸门。`get_day_trends`、`get_yesterday_data`、`get_distinct_date_data` 都是只读查询却挂了 `@with_session`，这条只读命令因此会抢三次进程级单写者闸门，并且排队超时时有权取消当时正在写的任务。现在改挂 `@with_read_session` 走独立读槽；WebConsole 面板调 `get_day_trends` 同样不再占写闸门。
- **🎨 调整** `core信息` 的渲染按「取数 / 画图」拆开：`_fetch_hw`、`_fetch_plugins_status` 和两组 `draw_data_analysis1` 的入参由主循环备好，PIL 全部移进 `_compose_status_card` 的工作线程。`draw_title` 仍留主循环，因为 `image_tools.draw_pic_with_ring` 是插件文档里公开的协程 API，改成同步属于破坏性变更。
- **🐛 修复** 新连接接入时不再误拆仍在服役的 `_Bot`。旧判据把 `_disconnected_at is None` 当成「断连超过 5 分钟」，而重连复用分支恰好会把它清回 `None`，于是每次重连都被判超时：实例被重建，`clear_send_queue()` 把在途回复全部丢弃，表现为「消息收得到、发不出去」。现在只有实例真的脱手套接字（`bot.bot is None`）才可能被判超时。[`5bfd0de9`](https://github.com/Genshin-bots/gsuid_core/commit/5bfd0de9)
- **🐛 修复** 旧连接的收尾只关闭自己的套接字。`close()` 期间同一 `bot_id` 登记了新连接时，收尾不删除该登记，也不把新 `_Bot` 标成已断开。套接字关闭后，`GsLogger` 推日志不再抛出 `WebSocketDisconnected`。[`9659c2ed`](https://github.com/Genshin-bots/gsuid_core/commit/9659c2ed)
- **🎨 调整** 知识嵌入按当前嵌入模型声明的最大输入 token 折算切分预算，未知模型按 512 token 留 32 个特殊 token；切法编号连同 token 上限一起进内容哈希，换模型会自动重切。[`ef79e92d`](https://github.com/Genshin-bots/gsuid_core/commit/ef79e92d)
- **🎨 调整** `core更新记录` 不带参数时改为同时给未发布段与上一已发布版；索引触发词补上 `目录`、`idx`、`menu`。[`d3d4e48c`](https://github.com/Genshin-bots/gsuid_core/commit/d3d4e48c)
- **🐛 修复** 群聊排队不再等 TTL 到期，委派派完即走，并把消息按发起人传给被委派的 subagent。[`926d3e50`](https://github.com/Genshin-bots/gsuid_core/commit/926d3e50)
- **📝 文档** 补充更新日志的写法约定，并把此前各版本的历史记录补齐。[`ed19361f`](https://github.com/Genshin-bots/gsuid_core/commit/ed19361f)
- **✨ 新增** 撤掉选择器，新增认知检索分页，委派改为内联等待。[`65c3f8c4`](https://github.com/Genshin-bots/gsuid_core/commit/65c3f8c4)
- **🐛 修复** `on_prefix` 触发器的空格匹配问题。[`87c06f11`](https://github.com/Genshin-bots/gsuid_core/commit/87c06f11)
- **🐛 修复** 软触发轮群转录缺失、兜底出戏修复与过程叙述闸。[`5fde13e0`](https://github.com/Genshin-bots/gsuid_core/commit/5fde13e0)
