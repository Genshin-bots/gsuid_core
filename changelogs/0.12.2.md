# 0.12.2 — 记忆中文 BM25 分词修复与本地静态嵌入支持

发布于 2026-11-18 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

记忆系统稀疏检索统一接入 `jieba` 中文分词，本地嵌入支持 FastEmbed 静态模型（`safetensors` + `mmap`）。

- **🐛 修复** 记忆系统 BM25 稀疏检索接入 `jieba` 中文分词，新写入及后续更新的片段、实体与边恢复中文词项匹配。
- **✨ 新增** 本地嵌入新增 FastEmbed 静态模型预设 `minishlab/potion-multilingual-128M`，默认启用 `mmap` 映射且无 ONNX 内存池占用。
- **⬆️ 依赖** `fastembed` 下限升至 `0.9.1`，同步更新版本号至 `0.12.2`。
