# 0.12.2 — 记忆中文 BM25 分词修复与本地静态嵌入支持

发布于 2026-11-18 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

记忆系统稀疏检索统一接入 `jieba` 中文分词，本地嵌入支持 FastEmbed 静态模型（`safetensors` + `mmap`）。

- **🐛 修复** 记忆系统 BM25 稀疏检索接入 `jieba` 中文分词，新写入及后续更新的片段、实体与边恢复中文词项匹配。 [`89e1c93f`](https://github.com/Genshin-bots/gsuid_core/commit/89e1c93f)
- **✨ 新增** 本地嵌入新增 FastEmbed 静态模型预设 `minishlab/potion-multilingual-128M`，默认启用 `mmap` 映射且无 ONNX 内存池占用。 [`89e1c93f`](https://github.com/Genshin-bots/gsuid_core/commit/89e1c93f)
- **⬆️ 依赖** `fastembed` 下限升至 `0.9.1`，同步更新版本号至 `0.12.2`。 [`89e1c93f`](https://github.com/Genshin-bots/gsuid_core/commit/89e1c93f)
- **✨ 新增** 生活手账升级为自我核与驻群定长分片，新增持久、当月、昨日与今日四层记忆、按月归档及个人笔记自动合并。 [`efba5c49`](https://github.com/Genshin-bots/gsuid_core/commit/efba5c49)
- **🐛 修复** 补齐子代理、图文发送、看板回灌与主动发言的手账回流，消除词元腰斩、协议尾块污染与未完结幻觉。 [`efba5c49`](https://github.com/Genshin-bots/gsuid_core/commit/efba5c49)
- **🐛 修复** 群聊区分引用历史图与本人新发图，关闭无关表情包强制自拍鉴定，支持多人连发点名聚批与简短数字直回。
- **🐛 修复** 补齐看板与子任务全生命周期控制，支持按 `#序号` 查进度、暂停或终结时立即中断在途执行及在途修改重派。
