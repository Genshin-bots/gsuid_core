# 0.12.2 — 记忆中文 BM25 分词修复与本地静态嵌入支持

发布于 2026-11-18 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

记忆系统稀疏检索统一接入 `jieba` 中文分词，本地嵌入支持 FastEmbed 静态模型（`safetensors` + `mmap`）。

- **🐛 修复** 记忆系统 BM25 稀疏检索接入 `jieba` 中文分词，新写入及后续更新的片段、实体与边恢复中文词项匹配。 [`89e1c93f`](https://github.com/Genshin-bots/gsuid_core/commit/89e1c93f)
- **✨ 新增** 本地嵌入新增 FastEmbed 静态模型预设 `minishlab/potion-multilingual-128M`，默认启用 `mmap` 映射且无 ONNX 内存池占用。 [`89e1c93f`](https://github.com/Genshin-bots/gsuid_core/commit/89e1c93f)
- **⬆️ 依赖** `fastembed` 下限升至 `0.9.1`，同步更新版本号至 `0.12.2`。 [`89e1c93f`](https://github.com/Genshin-bots/gsuid_core/commit/89e1c93f)
- **✨ 新增** 生活手账升级为自我核与驻群定长分片，新增持久、当月、昨日与今日四层记忆、按月归档及个人笔记自动合并。 [`efba5c49`](https://github.com/Genshin-bots/gsuid_core/commit/efba5c49)
- **🐛 修复** 补齐子代理、图文发送、看板回灌与主动发言的手账回流，消除词元腰斩、协议尾块污染与未完结幻觉。 [`efba5c49`](https://github.com/Genshin-bots/gsuid_core/commit/efba5c49)
- **🐛 修复** 群聊区分引用历史图与本人新发图，关闭无关表情包强制自拍鉴定，支持多人连发点名聚批与简短数字直回。 [`aaa8bd6a`](https://github.com/Genshin-bots/gsuid_core/commit/aaa8bd6a)
- **🐛 修复** 补齐看板与子任务全生命周期控制，支持按 `#序号` 查进度、暂停或终结时立即中断在途执行及在途修改重派。 [`aaa8bd6a`](https://github.com/Genshin-bots/gsuid_core/commit/aaa8bd6a)
- **✨ 新增** 网页搜索与抓取接入可选用提供方 `Keenable`，支持无 Key 公开端点与多 Key 池，默认链路与备用顺序保持不变。 [`3df7808f`](https://github.com/Genshin-bots/gsuid_core/commit/3df7808f)
- **🐛 修复** 群聊收件箱消解近窗原样复读，统一前置路由过滤换词起哄、旁述提及与其他 Bot 播报，打字停顿期插话自动补挂引用。 [`b57c4cb4`](https://github.com/Genshin-bots/gsuid_core/commit/b57c4cb4)
- **🐛 修复** 修复代理模式下模型 HTTP 连接池泄漏与重试叠乘导致的长时间卡死；群聊收件箱改为仅合并同一发言人连发，不同群友独立轮次回应。 [`8e7b4a81`](https://github.com/Genshin-bots/gsuid_core/commit/8e7b4a81)
- **⚡ 优化** 收敛群聊门控、线程切片与前置路由：显式 `@` 直通、高活跃群压制免唤醒续聊、未说完起手式拉窗，减少误判与上下文冗余。 [`a8ddc490`](https://github.com/Genshin-bots/gsuid_core/commit/a8ddc490)
- **🧹 清理** 移除 20 个未接线 Hook 点位、5 个占位套件槽位、失效工具 `mark_evidence` 与 2 个无效配置项，同步精简控制台诊断页。 [`38fc606a`](https://github.com/Genshin-bots/gsuid_core/commit/38fc606a)
- **🐛 修复** 群聊引用 Bot 历史播报回答他人时不再误判为显式 `@` 抢答，同步修复主动播报幽灵会话、命令回执待回应误标与跨日手账「刚刚经历」串入问题。 [`072f701c`](https://github.com/Genshin-bots/gsuid_core/commit/072f701c)
- **⚡ 优化** 自主行动与定时巡检共用主动发言表达层（支持按配置附带表情），去「刚才看到…」套话并隔离调研上下文，回复简短自然不复读数据。 [`1617d91e`](https://github.com/Genshin-bots/gsuid_core/commit/1617d91e)
- **✨ 新增** 绘图与 AIGC 子代理在执行模型支持识图时自动接入 `read_image`（长图/大图自动分段切片检视），`render_agent` 支持最多 4 次检视修改重渲。 [`c4c36052`](https://github.com/Genshin-bots/gsuid_core/commit/c4c36052)
- **✨ 新增** 按任务指定模型支持按单个能力代理（如 `render_agent`）分别覆盖主备配置，未覆盖时自动继承能力代理统一配置，并按代理分项统计 Token 用量。 [`1f9f23af`](https://github.com/Genshin-bots/gsuid_core/commit/1f9f23af)
- **⚡ 优化** 精简核心与 AI 启动常驻内存：重依赖按需懒加载、BM25 改用纯 Python 分词并自动迁移存量稀疏索引、静态嵌入模型直读 `safetensors` 绕过 ONNX。 [`6b1a85b7`](https://github.com/Genshin-bots/gsuid_core/commit/6b1a85b7)
- **✨ 新增** 启动时统计各插件导入内存增量并输出 Top-10（控制台插件列表新增 `memory_mb`），新增 `@on_ai_register` 装饰器支持插件延迟注册 AI 资产。 [`6b1a85b7`](https://github.com/Genshin-bots/gsuid_core/commit/6b1a85b7)
