# 0.8.3 — 日志变干净，历史日志可跳页

发布于 2025-09-13 · 本版 15 个提交 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

这一版分开处理日志与配置。控制台 `DEBUG` 日志不再打印 `locals`，多余 `log` 打印被删除。网页控制台的 `历史日志` 支持跳转页数，修改 `master` 与全局黑名单后无需重启。启动参数 `uv run core --dev` 上线，`HOST` 允许留空以同时监听 `IPv6` 与 `IPv4`。

- **✨ 新增** 启动参数 `uv run core --dev`。[`e910efb5`](https://github.com/Genshin-bots/gsuid_core/commit/e910efb5)
- **✨ 新增** 网页控制台修改 `master` 与全局黑名单后无需重启即生效（#139）。[`4669e2bf`](https://github.com/Genshin-bots/gsuid_core/commit/4669e2bf)
- **✨ 新增** 配置项 `HOST` 允许留空，同时监听 `IPv6` 与 `IPv4`（#137）。[`864e413e`](https://github.com/Genshin-bots/gsuid_core/commit/864e413e)
- **✨ 新增** 网页控制台 `历史日志` 支持跳转页数（#131）。[`94a2ebcf`](https://github.com/Genshin-bots/gsuid_core/commit/94a2ebcf)
- **🐛 修复** 偶发的图片截断问题；修复加载 Bot 数据时的一个特殊情况。[`fc81fc46`](https://github.com/Genshin-bots/gsuid_core/commit/fc81fc46) [`b78cc31a`](https://github.com/Genshin-bots/gsuid_core/commit/b78cc31a)
