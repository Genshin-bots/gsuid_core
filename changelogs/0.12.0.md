# 0.12.0 — 去正则统一路由与群聊记忆 v2

发布于 2026-11-08 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

记忆系统升级为 schema_v2：四态记忆代数、两阶段群聊摄入、五模态意图检索。启动时自动执行幂等净室迁移。

- **✨ 新增** 前置 `TurnRouter`：一次无思考低档调用统一意图、记忆模态、软触发与事务委托；常规对话固定 2 次模型调用。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867)
- **💥 破坏性** 记忆表升级到 schema_v2：保留四表 + 偏好，删除旧会话、事件、冲突、分类与分层图元数据；首次启动自动备份并重建四表、FTS5 与 Qdrant 四集合。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867)
- **✨ 新增** 两阶段摄入（Pass 1 分诊话题，Pass 2 产出实体、四态边、里程碑与偏好）、四态代数 `ADD / MERGE / SUPERSEDE / CONTRADICT` 与五种记忆检索意图。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867) [`9a7e1047`](https://github.com/Genshin-bots/gsuid_core/commit/9a7e1047)
- **⚡ 性能** Episode 词面召回改用 SQLite FTS5，记忆页补 `valid_at` 索引（83 万条从 5.2 秒降至毫秒级）；工具检索加入 CJK 二元语法 BM25 + 稠密 RRF。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867) [`9a7e1047`](https://github.com/Genshin-bots/gsuid_core/commit/9a7e1047) [`d9e9e489`](https://github.com/Genshin-bots/gsuid_core/commit/d9e9e489)
