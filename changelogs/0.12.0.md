# 0.12.0 — 去正则统一路由与群聊记忆 v2

发布于 2026-11-08 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

记忆系统升级为 schema_v2：四态记忆代数、两阶段群聊摄入、五模态意图检索。启动时自动执行幂等净室迁移。

- **✨ 新增** 前置 `TurnRouter`：一次无思考低档调用统一意图、记忆模态、软触发与事务委托；常规对话固定 2 次模型调用。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867)
- **💥 破坏性** 记忆表升级到 schema_v2：保留四表 + 偏好，删除旧会话、事件、冲突、分类与分层图元数据。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867)
- **⚗️ 数据库** 首次启动备份 SQLite 与群画像，自动重建四表、FTS5 与 Qdrant 四集合；重复启动不丢新数据。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867)
- **✨ 新增** 两阶段摄入：28 条 / 180 秒静默 / 1800 秒上限触发；Pass 1 分诊话题，Pass 2 一次产出实体、四态边、里程碑与偏好。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867)
- **✨ 新增** 四态代数 `ADD / MERGE / SUPERSEDE / CONTRADICT`：转述先 `staging`，本人确认或多源印证后升 `active`。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867) [`9a7e1047`](https://github.com/Genshin-bots/gsuid_core/commit/9a7e1047)
- **✨ 新增** 五种记忆意图：点查压制旧值，变更题展开版本链，时间线升序，总结题注入原文切片。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867) [`9a7e1047`](https://github.com/Genshin-bots/gsuid_core/commit/9a7e1047)
- **⚡ 性能** Episode 词面召回改用 SQLite FTS5，大群不再逐词全表 `LIKE`；记忆页跨范围首页补 `valid_at` 索引，83 万条从 5.2 秒降到毫秒级。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867) [`d9e9e489`](https://github.com/Genshin-bots/gsuid_core/commit/d9e9e489)
- **✨ 新增** 工具检索加入 CJK 二元语法 BM25 + 稠密 RRF，英文嵌入下中文口语仍能命中。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867) [`9a7e1047`](https://github.com/Genshin-bots/gsuid_core/commit/9a7e1047)
- **✨ 新增** WebConsole 虚拟分类投影与故事线接口；`/hiergraph/rebuild` 改为零 LLM 的 FTS5 + Qdrant 对账。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867) [`9a7e1047`](https://github.com/Genshin-bots/gsuid_core/commit/9a7e1047)
- **🎨 调整** 决策归档不再调用模型；关系温度不再扫情绪词，只消费结构化互动与记忆态度信号。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867)
- **💻 前端** 记忆页新增故事线页签、四态边标记、历史边开关与索引重建按钮；首屏只拉当前页签。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867)
- **🔖 升版** 升版至 `0.12.0`。[`55713867`](https://github.com/Genshin-bots/gsuid_core/commit/55713867)
- **🐛 修复** `find_tools` 按工具名查询时该工具不再被专用档截断挤掉；移除单轮墙钟软预算配置项，并拦截未创建后台任务或写操作的「做好再通知」空头承诺。[`9a7e1047`](https://github.com/Genshin-bots/gsuid_core/commit/9a7e1047) [`682c047e`](https://github.com/Genshin-bots/gsuid_core/commit/682c047e)
