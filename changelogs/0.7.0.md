# 0.7.0 — 改用 uv 启动，控制台加入历史日志

发布于 2025-01-15 · 本版 36 个提交 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

这一版给启动换了入口: 仓库根目录可以直接跑 `uv run core`，依赖声明也补齐了。网页控制台多出「历史日志」和「触发 CD」两块。群订阅公告、签到这类主动任务交给新模块 `gsuid_core.subscribe`。

- **📦** 发布 `0.7.0`: 根目录可用 `uv run core` 启动，依赖声明补齐，启动时区分运行环境。[`f255f23f`](https://github.com/Genshin-bots/gsuid_core/commit/f255f23f)
- **💥** 米游社基础请求类不再用 `httpx`，换成 `aiohttp`；继承该类的插件要跟着改写。[`ee008d6f`](https://github.com/Genshin-bots/gsuid_core/commit/ee008d6f)
- **✨** 新增模块 `gsuid_core.subscribe`，群订阅公告、签到等主动任务走它。[`2dda8aa0`](https://github.com/Genshin-bots/gsuid_core/commit/2dda8aa0)
