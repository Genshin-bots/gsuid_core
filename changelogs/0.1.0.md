# 0.1.0 — 项目起点：消息收发、多步会话、数据库基类与图片上传成型

发布于 2023-12-11 · 本版 139 个提交 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

仓库的第一段历史。`Bot` 收发协议、`MessageSegment` 消息段、数据库基类、插件安装与图片上传在同一时期定型，此后所有版本都长在这套骨架上。
