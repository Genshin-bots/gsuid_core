# 0.11.2 — 系统提示词可按组切换

发布于 2026-10-18 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

人格页可以切换系统提示词组，并改说话强度和建议字数。

- **✨ 新增** 网页控制台人格页用页签切换「系统提示词组」和「人格」。可以新建或复制一组，并在人格配置里选用。默认组与默认人格「早柚」的正文每次启动从程序写回，页面上不能改。主人、称呼、日期、字数用 `{{masters}}` 这类占位符，发送前再填。巡检决策和续聊软门末尾的 JSON 要求由程序固定，保存时改过的那句不保留。
- **🎨 调整** 网页控制台人格编辑页用滑块设置说话强度（0 到 100）和建议字数（5 到 400），滑块右侧可以输入数字。建议字数仍为 60 时，发送继续用说话强度那一档的字数。字段「宪法」改名为「基本规矩」。作答契约单独成段。收束句前面不再加 `---`。
- **💥 破坏性** 系统提示不再写台词硬上限。已保存的 `speech_len_hard` 不再读取。开场接任务应的长度改用说话强度档位：0–24 为 80 字，25–74 为 150 字，75–100 为 200 字。
- **✨ 新增** 出图代理 `render_agent` 可以调用新工具 `find_images` 找配图。工具按搜索词依次查插件图库、Firecrawl 图片搜索（没填 Key 时走免费档）、360 图片搜索，最后才是 Tavily（配了 Key 时）。下载并检查尺寸后把图交给出图使用。来源和顺序在 AI 配置「出图配图来源」（`render_image_sources`）里改，留空则不找图。
- **🎨 调整** `render_agent` 出的图默认逻辑宽为 840。页头和封面比更窄的画布更矮；全宽大图最多 3 处，其余用两列或左图右文，整图高宽比大约 2.2～3.8。
- **✨ 新增** AI 配置「允许嵌入配图」（`render_embed_images`），默认开启。开启时出图必须先 `find_images` 并把返回的图片写进长图，没写会被打回；关闭后 `render_agent` 不再挂这个工具，出图改用图标。
- **🎨 调整** HTML 出图时嵌入的图片最长边从 512px 提高到 1280px，不透明的图改存 JPEG。`icon:` 图标可以在地址后加 `?color=1d6fb8` 指定颜色。
- **🔖 升版** 升版至 `0.11.2`。
