# 0.11.2 — 系统提示词可按组切换

发布于 2026-10-18 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

人格页可以切换系统提示词组，并改说话强度和建议字数。

- **🎨 调整** 呈现层把过长的结构化正文先交给 `render_agent` 出图。当前人格未启用出图，或 `render_agent` 没有交出图片时，仍用 `render_md_to_bytes`。开关仍是 `render_long_markdown_as_image`。[`0c2f0cce`](https://github.com/Genshin-bots/gsuid_core/commit/0c2f0cce)
- **🎨 调整** `render_md_to_bytes` 的深色卡片改为近黑底、奶油色标题、金色小节。列表条目用横线分隔，表格表头用深金色。[`0c2f0cce`](https://github.com/Genshin-bots/gsuid_core/commit/0c2f0cce)

- **✨ 新增** 人格可以开启「命令补充」。默认关闭。[`526946ff`](https://github.com/Genshin-bots/gsuid_core/commit/526946ff)
- **✨ 新增** 开启后，命令回复发出时，当前 AI 会话写入用户原话和这次回复。只发图片、只发文字、图文混合分别用 `aside_image_probability`（默认 0.2）、`aside_text_probability`（默认 0.35）、`aside_mixed_probability`（默认 0.25）决定要不要再补一句人设点评，取值 0 到 1。`aside_allow_tools` 为真时，点评可以调用工具，并阅读这条命令所属插件目录里的源码。概率未抽中时不发点评，会话里仍保留这次命令和回复。[`526946ff`](https://github.com/Genshin-bots/gsuid_core/commit/526946ff)
- **✨ 新增** 同一条命令回执再次出现时，命令补充读已记下的建议，不再读源码。点评说明在系统提示词组的「命令补充」（`aside_comment`）。默认组每次启动从程序写回；要改这段，先复制一组。[`526946ff`](https://github.com/Genshin-bots/gsuid_core/commit/526946ff)
- **🎨 调整** 回执里的命令旁边，源码用「先」或「然后」写着另一步时，命令补充把这一步和回执里的命令说进同一句。[`526946ff`](https://github.com/Genshin-bots/gsuid_core/commit/526946ff)

- **✨ 新增** 网页控制台人格页用页签切换「系统提示词组」和「人格」。可以新建或复制一组，并在人格配置里选用。默认组与默认人格「早柚」的正文每次启动从程序写回，页面上不能改。主人、称呼、日期、字数用 `{{masters}}` 这类占位符，发送前再填。巡检决策和续聊软门末尾的 JSON 要求由程序固定，保存时改过的那句不保留。[`3075c52b`](https://github.com/Genshin-bots/gsuid_core/commit/3075c52b)
- **🎨 调整** 网页控制台人格编辑页用滑块设置说话强度（0 到 100）和建议字数（5 到 400），滑块右侧可以输入数字。建议字数仍为 60 时，发送继续用说话强度那一档的字数。字段「宪法」改名为「基本规矩」。作答契约单独成段。收束句前面不再加 `---`。[`3075c52b`](https://github.com/Genshin-bots/gsuid_core/commit/3075c52b)
- **💥 破坏性** 系统提示不再写台词硬上限。已保存的 `speech_len_hard` 不再读取。开场接任务应的长度改用说话强度档位：0–24 为 80 字，25–74 为 150 字，75–100 为 200 字。[`3075c52b`](https://github.com/Genshin-bots/gsuid_core/commit/3075c52b)
- **✨ 新增** 出图代理 `render_agent` 可以调用新工具 `find_images` 找配图。工具按搜索词依次查插件图库、Firecrawl 图片搜索（没填 Key 时走免费档）、360 图片搜索，最后才是 Tavily（配了 Key 时）。下载并检查尺寸后把图交给出图使用。来源和顺序在 AI 配置「出图配图来源」（`render_image_sources`）里改，留空则不找图。[`ff6cf494`](https://github.com/Genshin-bots/gsuid_core/commit/ff6cf494)
- **🎨 调整** `render_agent` 出的图默认逻辑宽为 840。页头和封面比更窄的画布更矮；全宽大图最多 3 处，其余用两列或左图右文，整图高宽比大约 2.2～3.8。[`ff6cf494`](https://github.com/Genshin-bots/gsuid_core/commit/ff6cf494)
- **✨ 新增** AI 配置「允许嵌入配图」（`render_embed_images`），默认开启。开启时出图必须先 `find_images` 并把返回的图片写进长图，没写会被打回；关闭后 `render_agent` 不再挂这个工具，出图改用图标。[`ff6cf494`](https://github.com/Genshin-bots/gsuid_core/commit/ff6cf494)
- **🎨 调整** HTML 出图时嵌入的图片最长边从 512px 提高到 1280px，不透明的图改存 JPEG。`icon:` 图标可以在地址后加 `?color=1d6fb8` 指定颜色。[`ff6cf494`](https://github.com/Genshin-bots/gsuid_core/commit/ff6cf494)
- **✨ 新增** 联网搜索与网页抓取接入 DeepSeek 官方接口。在 AI 配置里提供 `deepseek_config`（包含 API Key 池、搜索/抓取端点 URL 与内容解析开关），可作为 `websearch_provider` 与 `webfetch_provider` 的主用或备用源，并支持错误切换与自动分流。[`7f37359f`](https://github.com/Genshin-bots/gsuid_core/commit/7f37359f)
- **🔖 升版** 升版至 `0.11.2`。[`11535487`](https://github.com/Genshin-bots/gsuid_core/commit/11535487)
- **🐛 修复** 能力代理达到思考轮数上限时，会话日志写入本轮的模型和 token。历史调用页据此显示用量。[`accf11b2`](https://github.com/Genshin-bots/gsuid_core/commit/accf11b2)
- **🐛 修复** 能力代理在还剩两轮模型请求时收到收口提示，停止新的检索并用已有材料交付。[`accf11b2`](https://github.com/Genshin-bots/gsuid_core/commit/accf11b2)
- **🐛 修复** 能力代理仍然达到上限、且已经查到材料时，用这些材料写成交付交回看板。下游任务读到这份交付，而不是失败句。[`accf11b2`](https://github.com/Genshin-bots/gsuid_core/commit/accf11b2)
- **🐛 修复** 群聊 `[历史对话]` 保留 AI 发给其他群友的消息与图片主题。其他群友引用 AI 发出的纯图片消息时，上下文注入原收件人归属行，引用中的旧图不再按新上传附图触发调工具纠偏；本轮若选择沉默，同步撤销刚开启的免唤醒续聊窗口。[`9c8e93d6`](https://github.com/Genshin-bots/gsuid_core/commit/9c8e93d6)
- **✨ 新增** 主动消息发送工具 `send_message_by_ai` 支持传入 `image_ids` 参数一次性发送多张图片（单次最多 9 张），并支持部分失败容错与出站安全过滤插槽。[`7a94044d`](https://github.com/Genshin-bots/gsuid_core/commit/7a94044d)
- **✨ 新增** 通用网络搜图工具 `search_web_images`（`category="common"`），支持按关键词在插件图库、Firecrawl、360 与 Tavily 中检索并校验图片尺寸，返回可供 `send_message_by_ai` 发送的 `img_` 资源ID。[`7a94044d`](https://github.com/Genshin-bots/gsuid_core/commit/7a94044d)
- **🔒 安全** 网页控制台限流、HTTP Agent 封禁和 HTTP 访问日志在直连地址属于 `TRUSTED_IPS` 时，从第一行 `X-Forwarded-For` 右端取第一个合法且不在该列表中的地址；没有这项结果时才使用 `X-Real-IP`。非法地址丢弃。WebSocket 是否信任来源读取同一份列表，控制台保存后的下一次连接生效。[`bbaf1d1a`](https://github.com/Genshin-bots/gsuid_core/commit/bbaf1d1a)
- **🐛 修复** MCP HTTP 的 task group 被取消后，常驻任务退出这一代并进入新会话。[`754c3b48`](https://github.com/Genshin-bots/gsuid_core/commit/754c3b48)
- **🐛 修复** MCP HTTP 在状态码还没写给客户端时，把同一次请求交给新会话重放。[`754c3b48`](https://github.com/Genshin-bots/gsuid_core/commit/754c3b48)
- **🐛 修复** MCP HTTP 在状态码已经写出但正文没有结束时，只补结束块，本次不重放。[`754c3b48`](https://github.com/Genshin-bots/gsuid_core/commit/754c3b48)
- **🎨 调整** MCP HTTP 在客户端断开且子应用正常返回时，不重建会话。[`754c3b48`](https://github.com/Genshin-bots/gsuid_core/commit/754c3b48)
- **🐛 修复** 网页控制台选定的思考等级进入请求。OpenAI 兼容接口写 `reasoning_effort`：`enable` 为 `medium`，`disable` 为 `none`，`high` 为 `high`，`xhigh` 为 `xhigh`。模型名不在 pydantic-ai 的思考名单里时，Core 不再删掉这个字段。`adaptive` 仍然不传。上游拒绝该字段时，错误原样返回。Gemini 在模型名未被标成支持思考时，仍按所选档位发送 `thinking_level` 或 `thinking_budget`。[`0813356b`](https://github.com/Genshin-bots/gsuid_core/commit/0813356b)
- **✨ 新增** OpenAI 兼容配置的思考档位增加 `max`。选中后 Chat Completions 与 Responses 都写 `reasoning_effort=max`。模型名不在思考名单里也发送。上游拒绝时，错误原样返回。[`0813356b`](https://github.com/Genshin-bots/gsuid_core/commit/0813356b)
- **✨ 新增** 会话日志在每次模型请求发出后写入该请求 JSON 里的思考档位（`thinking_effort.effort`）。请求里没有这个字段时值为 `null`。服务日志打印同一档位。[`ffec3b0f`](https://github.com/Genshin-bots/gsuid_core/commit/ffec3b0f)
- **🐛 修复** 能力代理达到思考轮数上限触发收口交付时，会话日志 `token_usage` 累加主循环用量后再统一上报，避免漏记主循环消耗。
- **🐛 修复** 能力代理在沙箱初始化时将自身误判为交互主人格导致 `blocked_tool_names` 拦截自身专属工具的问题。
- **📊 统计** 后端与统计库 `total_tokens` 计算口径修正为 `input_tokens + output_tokens`（不再将已包含在输入中的 `cache_read` 重复叠加）。网页控制台 Token 堆叠图拆分为未缓存输入、缓存命中与输出三段，并将缓存率基数对齐为输入总量。
- **⚡ 性能** 能力代理工具返回阈值提高至 12,000 字且保留单条预览头，`run_code` 工具返回不再触发文件折叠。
- **⚡ 性能** 记忆实体抽取、偏好蒸馏、群摘要等结构化 JSON 任务默认关闭模型思考推理（`thinking=False`），减少非必要思考 Token 开销。
- **⚡ 性能** 定时巡检（Heartbeat）在群聊历史无新人类发言且无待合并事件时确定性跳过 LLM 决策。决策提示词中的当前时间行移至上下文末尾，提高前缀缓存命中率。
- **⚡ 性能** Provider 路由器新增会话粘性路由（Sticky Routing），同会话、群聊与能力任务优先复用同一 Provider 以维持前缀缓存。
- **✨ 增强** `run_code` 沙箱支持捕获 `print` 输出并与末行返回值合并交付，宿主工具返回值原样透传 Python dict/list，并在遇到 `NameError` 时返回当前可用工具函数清单。
- **✨ 增强** 句柄读取工具 `read_handle` 支持通过 `handle_ids` 批量读取多个句柄，并支持 `query` 关键词上下文段落窗口截取提取。
- **⚡ 性能** 主会话工具集在会话内只增不减，防止工具反复装卸破坏前缀缓存；`prefix_probe` 探针增加中段失配消息位置与近似失配前 Token 数记录。
