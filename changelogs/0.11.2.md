# 0.11.2 — 系统提示词可按组切换

发布于 2026-10-18 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

人格页支持按组切换系统提示词，出图代理与联网搜索多源接入，优化表情包协议与后台守护进程。

- **✨ 新增** 网页控制台支持「系统提示词组」管理与人格绑定，提示词组新增「框架底线」配置规范基础行为。 [`3075c52b`](https://github.com/Genshin-bots/gsuid_core/commit/3075c52b) [`2bc0d691`](https://github.com/Genshin-bots/gsuid_core/commit/2bc0d691)
- **💥 破坏性** 移除台词硬上限（`speech_len_hard`），人格说话强度改为滑块（0–100），建议字数支持 5–400 字自定义。 [`3075c52b`](https://github.com/Genshin-bots/gsuid_core/commit/3075c52b)
- **✨ 新增** 人格市场上线：支持浏览远程目录并一键导入 git 人格；导入的人格与表情包默认只读（可改启用范围或复制副本编辑）。 [`7bc9c15b`](https://github.com/Genshin-bots/gsuid_core/commit/7bc9c15b)
- **✨ 新增** 多人格好感度、自我认知、自身记忆与命令补充经验独立记录；新增社交主动度、社交耐力、闲时关注点、单话题跟进轮数四项配置及 72 小时私聊亲和契约。 [`d9ee6202`](https://github.com/Genshin-bots/gsuid_core/commit/d9ee6202) [`cdaf618c`](https://github.com/Genshin-bots/gsuid_core/commit/cdaf618c)
