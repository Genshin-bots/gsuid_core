# 0.11.2 — 系统提示词可按组切换

发布于 2026-10-18 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

人格页可以切换系统提示词组，并改说话强度和建议字数。

- **✨ 新增** 网页控制台人格页用页签切换「系统提示词组」和「人格」。可以新建或复制一组，并在人格配置里选用。默认组与默认人格「早柚」的正文每次启动从程序写回，页面上不能改。主人、称呼、日期、字数用 `{{masters}}` 这类占位符，发送前再填。巡检决策和续聊软门末尾的 JSON 要求由程序固定，保存时改过的那句不保留。
- **🎨 调整** 网页控制台人格编辑页用滑块设置说话强度（0 到 100）和建议字数（5 到 400），滑块右侧可以输入数字。建议字数仍为 60 时，发送继续用说话强度那一档的字数。字段「宪法」改名为「基本规矩」。作答契约单独成段。收束句前面不再加 `---`。
- **💥 破坏性** 系统提示不再写台词硬上限。已保存的 `speech_len_hard` 不再读取。开场接任务应的长度改用说话强度档位：0–24 为 80 字，25–74 为 150 字，75–100 为 200 字。
- **🔖 升版** 升版至 `0.11.2`。
