# 0.11.2 — 系统提示词可按组切换

发布于 2026-10-18 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

人格页可以切换系统提示词组，并改说话强度和建议字数。

- **🎨 调整** 呈现层把过长的结构化正文先交给 `render_agent` 出图。当前人格未启用出图，或 `render_agent` 没有交出图片时，仍用 `render_md_to_bytes`。开关仍是 `render_long_markdown_as_image`。[`0c2f0cce`](https://github.com/Genshin-bots/gsuid_core/commit/0c2f0cce)
- **🎨 调整** `render_md_to_bytes` 的深色卡片改为近黑底、奶油色标题、金色小节。列表条目用横线分隔，表格表头用深金色。[`0c2f0cce`](https://github.com/Genshin-bots/gsuid_core/commit/0c2f0cce)

- **✨ 新增** 人格可以开启「命令补充」。默认关闭。[`526946ff`](https://github.com/Genshin-bots/gsuid_core/commit/526946ff)
- **✨ 新增** 开启后，命令回复发出时，当前 AI 会话写入用户原话和这次回复。只发图片、只发文字、图文混合分别用 `aside_image_probability`（默认 0.2）、`aside_text_probability`（默认 0.35）、`aside_mixed_probability`（默认 0.25）决定要不要再补一句人设点评，取值 0 到 1。`aside_allow_tools` 为真时，点评可以调用工具，并阅读这条命令所属插件目录里的源码。概率未抽中时不发点评，会话里仍保留这次命令和回复。[`526946ff`](https://github.com/Genshin-bots/gsuid_core/commit/526946ff)
- **✨ 新增** 同一条命令回执再次出现时，命令补充读已记下的建议，不再读源码。点评说明在系统提示词组的「命令补充」（`aside_comment`）。默认组每次启动从程序写回；要改这段，先复制一组。[`526946ff`](https://github.com/Genshin-bots/gsuid_core/commit/526946ff)
- **🎨 调整** 回执里的命令旁边，源码用「先」或「然后」写着另一步时，命令补充把这一步和回执里的命令说进同一句。[`526946ff`](https://github.com/Genshin-bots/gsuid_core/commit/526946ff)

- **✨ 新增** 网页控制台人格页用页签切换「系统提示词组」和「人格」。可以新建或复制一组，并在人格配置里选用。默认组与默认人格「早柚」的正文每次启动从程序写回，页面上不能改。主人、称呼、日期、字数用 `{{masters}}` 这类占位符，发送前再填。巡检决策和续聊软门末尾的 JSON 要求由程序固定，保存时改过的那句不保留。[`3075c52b`](https://github.com/Genshin-bots/gsuid_core/commit/3075c52b)
- **🎨 调整** 网页控制台人格编辑页用滑块设置说话强度（0 到 100）和建议字数（5 到 400），滑块右侧可以输入数字。建议字数仍为 60 时，发送继续用说话强度那一档的字数。字段「宪法」改名为「基本规矩」。作答契约单独成段。收束句前面不再加 `---`。[`3075c52b`](https://github.com/Genshin-bots/gsuid_core/commit/3075c52b)
- **💥 破坏性** 系统提示不再写台词硬上限。已保存的 `speech_len_hard` 不再读取。开场接任务应的长度改用说话强度档位：0–24 为 80 字，25–74 为 150 字，75–100 为 200 字。[`3075c52b`](https://github.com/Genshin-bots/gsuid_core/commit/3075c52b)
- **✨ 新增** 出图代理 `render_agent` 可以调用新工具 `find_images` 找配图。工具按搜索词依次查插件图库、Firecrawl 图片搜索（没填 Key 时走免费档）、360 图片搜索，最后才是 Tavily（配了 Key 时）。下载并检查尺寸后把图交给出图使用。来源和顺序在 AI 配置「出图配图来源」（`render_image_sources`）里改，留空则不找图。[`ff6cf494`](https://github.com/Genshin-bots/gsuid_core/commit/ff6cf494)
- **🎨 调整** `render_agent` 出的图默认逻辑宽为 840。页头和封面比更窄的画布更矮；全宽大图最多 3 处，其余用两列或左图右文，整图高宽比大约 2.2～3.8。[`ff6cf494`](https://github.com/Genshin-bots/gsuid_core/commit/ff6cf494)
- **✨ 新增** AI 配置「允许嵌入配图」（`render_embed_images`），默认开启。开启时出图必须先 `find_images` 并把返回的图片写进长图，没写会被打回；关闭后 `render_agent` 不再挂这个工具，出图改用图标。[`ff6cf494`](https://github.com/Genshin-bots/gsuid_core/commit/ff6cf494)
- **🎨 调整** HTML 出图时嵌入的图片最长边从 512px 提高到 1280px，不透明的图改存 JPEG。`icon:` 图标可以在地址后加 `?color=1d6fb8` 指定颜色。[`ff6cf494`](https://github.com/Genshin-bots/gsuid_core/commit/ff6cf494)
