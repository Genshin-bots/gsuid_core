# 0.11.2 — 系统提示词可按组切换

发布于 2026-10-18 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

人格页可以切换系统提示词组，并改说话强度和建议字数。

- **✨ 新增** 人格配置增加「表情频率」`meme_frequency`，取值 0 到 100，默认 50。0–24 写「少用」，25–74 写「闲聊时大约每五到八次回复用一次」，75–100 写「大约每两到三次回复用一次」。这个值只改系统提示里的这一句，不限流，也不影响选图。[`aafbdc7f`](https://github.com/Genshin-bots/gsuid_core/commit/aafbdc7f)
- **🎨 调整** 默认提示词组的表情协议写明适合发和不发的场景，并说明表情不算台词字数。自定义提示词组保留原正文；要用新正文，重新复制默认组或手动加 `{{meme_frequency}}`。[`aafbdc7f`](https://github.com/Genshin-bots/gsuid_core/commit/aafbdc7f)
- **💥 破坏性** 删除 `send_meme` 工具。主人格只用回复里的 `<meme:情绪>` 或 `<meme:情绪 场景>` 发表情。人格「显式工具白名单」里的 `send_meme` 不再生效，可以删掉。[`aafbdc7f`](https://github.com/Genshin-bots/gsuid_core/commit/aafbdc7f)
- **🎨 调整** AI 发出的表情在群聊历史里写成 `[表情:情绪]`，不再写成 `[图片]`。[`aafbdc7f`](https://github.com/Genshin-bots/gsuid_core/commit/aafbdc7f)
- **🐛 修复** `<meme:情绪 场景>` 的场景词传给选图。之前整串当成情绪词。[`aafbdc7f`](https://github.com/Genshin-bots/gsuid_core/commit/aafbdc7f)

- **🎨 调整** `render_agent` 出图前先按内容选版式，写在 `gs-page` 的 `layout-*` 上。版式有 8 种：图文专题 `feature`、图鉴 `gallery`、专题解读 `magazine`、数据看板 `dashboard`、排行 `ranking`、对比 `compare`、时间线 `timeline`、简报 `brief`。系统提示不再要求每张图都用照片页头，也不再给唯一一份整页骨架。整图高宽比只保留上限 3.8。[`d4cb6f00`](https://github.com/Genshin-bots/gsuid_core/commit/d4cb6f00)
- **✨ 新增** 出图组件库增加页头 `gs-band`（色带）、`gs-split`（左文右图）、`gs-stat-hero`（大数字）和 `gs-hero tall`（封面）。主体增加排行 `gs-rank`、对比 `gs-compare-*`、引言 `gs-quote`、步骤 `gs-steps`、三列图块 `gs-grid cols-3`，以及 `gs-row top`、`gs-avatar lg`、`gs-thumb sm`。[`d4cb6f00`](https://github.com/Genshin-bots/gsuid_core/commit/d4cb6f00)
- **🎨 调整** 「允许嵌入配图」开启时，只有 `feature`、`gallery`、`magazine` 三种版式必须先 `find_images` 并把图写进长图。数据看板、排行、对比、时间线、简报不放照片也能出图。没写 `layout-*` 的 HTML 仍按必须有照片处理。[`d4cb6f00`](https://github.com/Genshin-bots/gsuid_core/commit/d4cb6f00)
- **🐛 修复** `render_chart_spec(signed=true)` 的正值柱从绿色改为红色，负值柱从红色改为绿色，和组件库的 `gs-up` / `gs-down` 一致。暗色主题 `ink` 的 `gs-up` / `gs-down` 改用亮一档的红和绿。之前同一张图里数字是红涨、柱子是绿涨，模型因此关掉 `signed`。[`d4cb6f00`](https://github.com/Genshin-bots/gsuid_core/commit/d4cb6f00)

- **🐛 修复** 网页控制台实时聊天在中文 Windows 上把会话索引写成系统编码。下次按 UTF-8 读取时，中文名字报错，侧栏被当成空的。现在读写都用 UTF-8。已经写成系统编码的索引和会话，下一次读取时改写成 UTF-8。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **🎨 调整** 文字发完之后，表情包再等 1 秒才发出。文字气泡的间隔是字数除以 7，最短 0.5 秒，最长 3 秒。表情没有字数，按 7 个字计算。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **🎨 调整** 表情写入磁盘前，Core 把短边收成 156 像素，长边按原比例缩放。短边已经是 156 像素的文件不重新编码。GIF 和动态 WebP 的每一帧都缩放。采集、上传、`.meme` 导入和人格整包导入都走这一步。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)

- **✨ 新增** OpenAI 兼容配置的模型名单增加 `MiniMax-M3` 和 `MiniMax-M3.1-Flash`。是否看图仍由该配置的「模型支持能力」决定。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **🎨 调整** 表情打标和 `send_meme` 用同一份词表。情绪含点头，以及难过、生气、害羞、疑惑、害怕、嫌弃、发呆、微笑、大笑、大哭、暴怒、好的、不要、谢谢、抱歉、加油、挥手、比心、不知道。场景是日常、吐槽、卖萌、怼人、安慰、庆祝、晚安、早安。按这句话的意思选词，不按文件名填。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **🎨 调整** 模型看 GIF 或动态 WebP 时，按时间收成最多 16 张静图。不超过 16 帧时一帧一张；17 到 48 帧每张拼 3 帧；49 到 64 帧每张拼 4 帧；再多每张拼 5 帧，超过 80 帧就等距取 80 帧。每帧放进约 300 像素的方格，从左到右是时间顺序。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **✨ 新增** `GET /api/meme/thumb/{meme_id}` 返回长边 160 像素的 JPEG。表情 ID 是内容哈希，同一张图的预览可以缓存。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **✨ 新增** 人格配置增加「允许表情回复」。打开后，系统提示写入 `<meme:情绪>` 协议和同一份情绪、场景词表。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **🎨 调整** 去掉表情包模块总开关。采集仍由「自动采集群聊图片」控制，打标仍由「启用 VLM 打标」控制。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **🐛 修复** 文件已经不在磁盘上的表情会从库里删掉，读图时不再反复报错。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)

- **💥 破坏性** 升级之后，`send_meme` 和回复里的 `<meme:>` 只从该人格已挂载的表情包里选图。`pick()` 不再先查 `persona_{人格名}` 再查 `common`。没有绑定行时不发送图片。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **💥 破坏性** `persona_hint` 为 `common` 或空字符串、且不在 `inbox` / `rejected` 的图，成为「通用表情包」的成员。每个已有人格默认挂载这个包。磁盘上的 `common` 目录不改名。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **💥 破坏性** 其他 `persona_hint` 各自成为一个包，不自动挂载。升级后名为「摆烂」的人格不会再因为目录 `persona_摆烂` 发出那张图，除非操作者把那个包挂上。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **🎨 调整** 删光某个格的绑定之后，该人格不再发表情，直到操作者重新绑定。保存 `persona.md` 和下一次启动不会把「通用表情包」加回去。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **✨ 新增** 一个人格最多挂载 16 个表情包。第 17 个绑定返回错误。「通用表情包」占 1 个名额。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **✨ 新增** 人格整包可以导出、导入。压缩包含 `persona.md`、头像、立绘、音频、`config.json`、`persona.json`，以及该人格已挂载的表情包图片和标签。导入后这些包挂到该人格。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)
- **🎨 调整** 打标成功且当时在 `inbox` 的图移到 `common`。尚未归过包、且没有指定包的第一次成功，该图成为「通用表情包」的成员。VLM 的 `persona_hint` 留在列上供人查看，不再新建 `persona_{名字}` 目录。[`4fd85b8d`](https://github.com/Genshin-bots/gsuid_core/commit/4fd85b8d)

- **🎨 调整** 呈现层把过长的结构化正文先交给 `render_agent` 出图。当前人格未启用出图，或 `render_agent` 没有交出图片时，仍用 `render_md_to_bytes`。开关仍是 `render_long_markdown_as_image`。[`0c2f0cce`](https://github.com/Genshin-bots/gsuid_core/commit/0c2f0cce)
