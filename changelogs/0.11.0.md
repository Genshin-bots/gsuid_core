# 0.11.0 — 消息吞吐最优 3.3x，记忆注入预算统一，人格能力做成花名册

发布于 2026-09-30 · 本版 59 个提交 · 提交范围见 `pyproject.toml` 的 `version` 变动 · [返回索引](CHANGELOG.md)

消息吞吐与命令匹配最优可达 `3.3x`，阻塞 IO 卸到线程池；记忆注入预算统一，人格能力做成花名册。

- **✨ 新增** 管理员在网页控制台「关系温度」页可列出全部已打分用户，每行含分数、档位、上次原因与当日涨扣。`GET /api/relationship/list` 对非管理员返回 403；`bot_id` 留空列出全部 bot。[`f8c6dd20`](https://github.com/Genshin-bots/gsuid_core/commit/f8c6dd20)
- **🎨 调整** `core更新记录` 每条改动的作者头像和 commit 短号跟在标题后。升版之后的提交算进当前版本；当前版超过 6 个提交时默认图不再带上一版。分类顺序为优化、新增、调整、安全、修复。索引触发词含 `目录`、`idx`、`menu`。[`d3d4e48c`](https://github.com/Genshin-bots/gsuid_core/commit/d3d4e48c)
- **✨ 新增** MCP 客户端调用出图工具时，Core 把 `bot.send` 的 PNG、JPEG、GIF、WebP 放进工具结果。单次最多 4 张，单张最多 2MB；外链超时或被拒时保留已取回的内容；非图片二进制只记份数；认 `link://`；结果不提示 `send_message_by_ai`。[`6c733658`](https://github.com/Genshin-bots/gsuid_core/commit/6c733658)
- **🔒 安全** Core 替 MCP 拉图时不请求回环、链路本地和云元数据地址，跳转后每一跳也检查。[`6c733658`](https://github.com/Genshin-bots/gsuid_core/commit/6c733658)
- **🐛 修复** 适配器一帧解不出 `MessageReceive` 时写警告并跳过，连接保持。[`9e4ad01b`](https://github.com/Genshin-bots/gsuid_core/commit/9e4ad01b)
